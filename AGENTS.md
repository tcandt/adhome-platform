# Project UI rules

For UI work throughout this project, read and apply [the Animate UI skill](docs/skills/animate-ui/SKILL.md).

- Use the installed `@animate-ui/react` components and primitives for interface motion, dialogs, loading and progress. Reuse the project's shared components.
- Progress and success must follow actual completed work and verified server responses. Never simulate completion with a timer.
- Preserve accessibility, reduced-motion preferences, mobile layouts and existing business behavior.
- This UI policy does not require changes to unrelated backend work.
