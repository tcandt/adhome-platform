# Vietnam Administrative Directory

Snapshot retrieved on November 3, 2026 from https://provinces.open-api.vn/api/v2/?depth=2.
Contains 34 province-level units and 3,321 commune-level units returned by API v2.
The directory follows the two-level administrative structure, without district-level fields.
It is bundled locally so address suggestions remain available without third-party runtime requests.
Names and codes are preserved from the provider. Free-text entry remains supported for existing addresses and future changes.
